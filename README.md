`1. 3. 4.`  
`가. 나. 나. 라.`  
처럼 순번이 꼬이는 일이 은근히 자주 생깁니다.

`1. 2. 3.` / `가. 나. 다.` 순번을 자동으로 다시 정리해주는 간단한 웹 도구입니다.

## 📋 통째로 붙여넣기

이미 한글이나 다른 문서에서 작성한 공문을 그대로 붙여넣을 수 있습니다.

예를 들어 아래처럼 번호가 뒤섞인 공문을 붙여넣으면

```text
1. 관련: 학돌중학교-1234(2026. 8. 5.) 
3. 2026학년도 교직원 안전교육을 다음과 같이 실시하고자 합니다.
  가. 일시: 2026. 8. 20.(목) 15:00
  나. 장소: 시청각실
  나. 대상: 전 교직원
  라. 내용: 생활안전 및 응급상황 대응 교육
4. 행정사항: 전 교직원은 교육에 참석하여 주시기 바랍니다.

붙임 1. 교직원 안전교육 계획(안) 1부.
      22. 교육자료 1부. 끝.
```

공문핏이 순번을 다시 정리해

```text
1. 관련: 학돌중학교-1234(2026. 8. 5.)
2. 2026학년도 교직원 안전교육을 다음과 같이 실시하고자 합니다.
  가. 일시: 2026. 8. 20.(목) 15:00
  나. 장소: 시청각실
  다. 대상: 전 교직원
  라. 내용: 생활안전 및 응급상황 대응 교육
3. 행정사항: 전 교직원은 교육에 참석하여 주시기 바랍니다.

붙임 1. 교직원 안전교육 계획(안) 1부.
      2. 교육자료 1부. 끝.
```

처럼 정리합니다.

- `1. 2. 3.` 숫자 순번 자동 정리
- `가. 나. 다.` 한글 순번 자동 정리
- `1) 2) 3)` 하위 숫자 순번 자동 정리
- `가) 나) 다)` 하위 한글 순번 자동 정리
- 항목 단계에 따라 들여쓰기를 `0칸 → 2칸 → 4칸 → 6칸`으로 통일
- 붙임 번호는 본문 숫자와 구분하여 정리
- 붙임이 1개면 번호 없이 `붙임` 뒤 2칸에 문서명을 표시
- 붙임이 2개 이상이면 첫 번호는 `붙임` 뒤 2칸, 2번부터는 숫자 앞을 6칸으로 통일
- 본문 마지막에 `끝.`이 없으면 마침표 뒤 두 칸을 띄워 `.  끝.` 자동 추가
- 상단 도움말에서 빠른 사용법과 자동 정리 범위를 바로 확인
- `1.관련`, `가.일시`, `1)세부내용`, `가)준비물`처럼 순번 뒤 공백이 없어도 인식
- 날짜처럼 `2026. 8. 20.` 형식의 숫자는 순번으로 처리하지 않음
- 일반 문장과 빈 줄은 그대로 유지

## ✍️ 직접 작성

공문을 처음부터 작성할 때는 항목을 칸칸이 입력할 수 있습니다.

빈 항목은 제외하고 필요한 항목만 모아  
`가. 나. 다. 라.` 순번을 자동으로 정리합니다.

---

## ✏️ 결과 확인·수정

정리된 결과는 오른쪽 결과창에서 바로 확인할 수 있습니다.

필요하면 결과 내용을 직접 수정한 뒤 사용할 수 있습니다.

- 결과 직접 수정
- 클립보드 복사
- TXT 파일 저장
- 다시 정리
- 초기화

복사하거나 TXT로 저장할 때는 **결과창에서 최종 수정한 내용 그대로** 사용됩니다.

## 💡 이런 때 사용하세요

- 기존 공문을 복사해서 수정하다 번호가 꼬였을 때
- `1. 3. 4.`처럼 숫자 순번이 틀어졌을 때
- `가. 나. 나. 라.`처럼 가나다 순서가 중복됐을 때
- 항목을 추가하거나 삭제하면서 번호가 엉켰을 때
- 붙임 번호를 다시 맞추기 귀찮을 때
- 공문 작성 후 번호만 빠르게 정리하고 싶을 때
