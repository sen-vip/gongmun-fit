# 📝 공문핏

**공문핏**은 공문 본문 작성 시 사용하는 번호 체계를 자동으로 정리해주는 웹 도구입니다.

비워둔 항목은 건너뛰고, 입력한 내용만 공문 형식에 맞게 정리하여 공문 작성 시간을 줄여줍니다.

바로가기

👉 공문핏 바로가기 https://sen-vip.github.io/gongmun-fit/

---

## ✨ 주요 기능

* 공문 제목 입력
* 관련 문서 입력 및 자동 정리
* 본문 항목 자동 번호 정리
* 사용하지 않는 항목 자동 제외
* 붙임 문구 자동 생성
* 결과 미리보기 제공
* 결과 복사 기능
* TXT 파일 저장 기능
* 입력 초기화 기능
* 외부 전송 없이 브라우저에서만 실행

---

## 🧾 이런 상황에 사용해요

공문을 작성하다 보면 중간 항목을 빼거나 추가할 때마다
`가, 나, 다, 라...` 번호를 다시 고쳐야 하는 경우가 많습니다.

공문핏은 사용하지 않는 항목을 비워두면
입력된 항목만 남겨 공문 번호 체계를 자동으로 다시 정리합니다.

---

## 🚀 사용 방법

1. 공문 제목을 입력합니다.
2. 관련 문서가 있으면 관련 항목에 입력합니다.
3. 본문에 필요한 항목만 입력합니다.
4. 붙임이 있으면 붙임 항목을 입력합니다.
5. **공문 생성하기** 버튼을 누릅니다.
6. 오른쪽 결과 미리보기에서 정리된 공문 본문을 확인합니다.
7. 필요한 경우 **복사하기** 또는 **TXT 저장** 버튼을 사용합니다.

## 📌 입력 예시

### 공문 제목

```text
2030학년도 미래 교육 실시
```

### 관련

```text
1. AI과-1234(2030.10.10.)
```

### 본문

```text
2. 2000학년도 미래 교육을 다음과 같이 실시하고자 합니다.
  가. 일시: 2030. 10. 11.(수) 15:00~16:00
  나. 장소: 교내 강당
  다. 대상: 전교생
  라. 내용: 미래교육
  마. 소요예산: 금500,000원(금오십만원)
  바. 강사: senvip
```

### 붙임

```text
계획안 1부.
```
