# 📐 공문핏 Gongmun Fit

**공문 번호와 들여쓰기를 한 번에 정리하는 웹 도구입니다.**

공문을 수정하다 보면 숫자가 빠지거나 `가. 나. 다.` 순서가 꼬이고, 항목마다 들여쓰기가 달라질 때가 있습니다.

공문핏에 작성한 공문을 그대로 붙여넣으면 본문 순번, 하위 항목, 붙임 번호와 마지막 `끝.`까지 공문 형식에 맞게 정리합니다.

[공문핏 바로가기](https://sen-vip.github.io/gongmun-fit/)

---

## 사용 방법

1. 작성한 공문을 `통째로 붙여넣기`에 붙여넣습니다.
2. `순번 정리하기`를 누릅니다.
3. 오른쪽 결과를 확인한 뒤 복사하거나 TXT로 저장합니다.

정리된 결과는 오른쪽 화면에서 직접 수정할 수 있습니다. 수정한 내용은 `복사하기`와 `TXT 저장`에 그대로 반영됩니다.

---

## 이렇게 정리됩니다

정리 전:

```text
7. 관련: 학돌중학교-1234(2026. 8. 5.)
3. 2026학년도 교직원 안전교육을 다음과 같이 실시하고자 합니다.
가. 일시: 2026. 8. 20.(목) 15:00
    라. 내용: 생활안전 및 응급상황 대응
  6) 생활안전교육
9) 응급처치교육
다) 실습
        마) 질의응답
9. 행정사항: 담당자는 교육자료를 준비합니다.

붙임 5. 교직원 안전교육 계획(안) 1부.
  22. 참석자 명단 서식 1부.
```

정리 후:

```text
1. 관련: 학돌중학교-1234(2026. 8. 5.)
2. 2026학년도 교직원 안전교육을 다음과 같이 실시하고자 합니다.
  가. 일시: 2026. 8. 20.(목) 15:00
  나. 내용: 생활안전 및 응급상황 대응
    1) 생활안전교육
    2) 응급처치교육
      가) 실습
      나) 질의응답
3. 행정사항: 담당자는 교육자료를 준비합니다.

붙임  1. 교직원 안전교육 계획(안) 1부.
        2. 참석자 명단 서식 1부.  끝.
```

문장 내용과 날짜는 유지하고 순번과 들여쓰기만 다시 맞춥니다.

---

## 정리 기준

| 항목         | 정리 방식                         |
| ---------- | ----------------------------- |
| `1. 2. 3.` | 들여쓰기 없음                       |
| `가. 나. 다.` | 앞에 2칸                         |
| `1) 2) 3)` | 앞에 4칸                         |
| `가) 나) 다)` | 앞에 6칸                         |
| 붙임 1개      | 번호 없이 `붙임` 뒤 2칸에 내용 표시        |
| 붙임 2개 이상   | 첫 번호는 `붙임` 뒤 2칸, 2번부터 숫자 앞 8칸 |
| 문서 마지막     | `.  끝.` 자동 추가                 |

순번 앞에 공백이나 탭이 섞여 있어도 단계별 들여쓰기로 통일합니다.

`2026. 8. 20.`처럼 날짜로 사용된 숫자는 본문 순번으로 처리하지 않습니다.

---

## 붙임 작성 예시

붙임이 1개인 경우:

```text
붙임  계획안 1부.  끝.
```

붙임이 2개 이상인 경우:

```text
붙임  1. 계획안 1부.
        2. 견적서 1부.
        3. 산출내역서 1부.  끝.
```

---

## 직접 작성

공문을 처음부터 작성할 때는 `직접 작성`을 선택할 수 있습니다.

관련 문서, 본문, 세부 항목과 붙임을 칸마다 입력하면 빈 항목은 제외하고 공문 형태로 만들어 줍니다.

붙임명만 입력하면 `1부.`와 필요한 붙임 번호가 자동으로 붙습니다.

---

## 이런 때 사용하세요

* 기존 공문을 복사해 수정하다 순번이 꼬였을 때
* 항목을 추가하거나 삭제해 번호를 다시 맞춰야 할 때
* `가. 나. 나. 라.`처럼 가나다 순서가 중복됐을 때
* 본문과 하위 항목의 들여쓰기가 제각각일 때
* 붙임 번호와 마지막 `끝.`을 빠르게 정리하고 싶을 때

---

## 개인정보 안내

입력한 공문 내용은 외부 서버로 전송되지 않습니다.

별도의 회원가입이나 프로그램 설치 없이 브라우저에서 사용할 수 있습니다. 공용 컴퓨터에서는 사용 후 입력 내용을 지워 주세요.
