# 📐 공문핏 Gongmun Fit

**공문 번호, 이제 직접 맞추지 마세요.**

공문을 작성하다 보면
`가. 나. 다. 다. 마.`
`1. 2. 4.`
처럼 순번이 꼬이는 일이 은근히 자주 생깁니다.

**공문핏**은 공문 내용을 입력하거나 이미 작성한 공문을 그대로 붙여넣으면
`1. 2. 3.` / `가. 나. 다.` 순번을 자동으로 정리해주는 간단한 웹 도구입니다.

👉 **바로가기**
https://sen-vip.github.io/gongmun-fit/

## ✨ 주요 기능

### ✍️ 직접 작성

항목을 칸칸이 입력하면 빈 항목을 제외하고 순번을 자동으로 정리합니다.

예를 들어

```text
가. 일시
나. 장소
다. 대상
마. 기타
```

처럼 입력 순서가 달라도 결과에서는 자연스럽게

```text
가. 일시
나. 장소
다. 대상
라. 기타
```

형태로 정리할 수 있습니다.

### 📋 통째로 붙여넣기

이미 한글이나 다른 문서에서 작성한 공문도 다시 입력할 필요가 없습니다.

공문 전체를 그대로 붙여넣으면

```text
1. 관련
4. 다음과 같이 실시하고자 합니다.
   가. 일시
   다. 장소
   다. 대상

붙임  1. 계획(안) 1부.
4. 견적서 1부.  끝.
```

↓

```text
1. 관련
2. 다음과 같이 실시하고자 합니다.
   가. 일시
   나. 장소
   다. 대상

붙임  1. 계획(안) 1부.
2. 견적서 1부.  끝.
```

처럼 순번을 다시 정리합니다.

* `1. 2. 3.` 숫자 순번 정리
* `가. 나. 다.` 한글 순번 정리
* 숫자 문단 아래 한글 항목은 별도로 정리
* `붙임 1. 2.` 순번은 본문과 구분하여 정리
* 일반 문장과 빈 줄은 그대로 유지
* 날짜처럼 `2026. 8. 20.` 형식의 숫자는 순번으로 처리하지 않음

## 💡 이런 때 사용하세요

* 공문을 다 작성했는데 `가나다` 순서가 꼬였을 때
* 항목을 추가하거나 삭제하면서 번호가 틀어졌을 때
* `1. 2. 3.` 번호를 다시 맞추기 귀찮을 때
* 기존 공문을 복사해서 수정하다 순번이 뒤섞였을 때
* 공문 작성 전 순번을 신경 쓰지 않고 내용부터 작성하고 싶을 때
