# 📝 공문핏

공문을 **통째로 붙여넣거나 직접 작성하면** `1. 2. 3.` / `가. 나. 다.` 순번을 자동으로 정리해주는 간단한 웹 도구입니다.

## 📋 통째로 붙여넣기 — 기본 사용

이미 작성한 공문을 그대로 붙여넣으면 순번을 다시 맞춥니다.

- 본문 `1. 2. 3.` 순번 자동 재정렬
- 숫자 문단 아래 `가. 나. 다.` 순번 별도 재정렬
- `붙임 1. 2.` 번호는 본문과 분리해 재정렬
- `2026. 8. 20.` 같은 날짜는 번호로 오인하지 않도록 보호
- 일반 문장, 빈 줄, 본문 내용은 그대로 유지
- 확장 가나다 순번 `가~하 → 거~허 → 고~호` 지원

예시:

```text
1. 관련
4. 다음과 같이 실시하고자 합니다.
   가. 일시
   다. 장소
   다. 대상

붙임  1. 계획(안) 1부.
      4. 견적서 1부.  끝.
```

↓

```text
1. 관련
2. 다음과 같이 실시하고자 합니다.
   가. 일시
   나. 장소
   다. 대상

붙임  1. 계획(안) 1부.
      2. 견적서 1부.  끝.
```

## ✍️ 직접 작성

새 공문을 처음부터 작성할 때는 칸칸이 입력하는 방식도 사용할 수 있습니다.

- 공문 제목 입력
- 관련 문서 입력
- 본문 문장 입력
- 세부 항목 입력 및 추가
- 붙임 문서 입력
- 빈 항목 제외 후 가나다 자동 재정렬

## ✨ 결과 활용

- 결과 미리보기
- 클립보드 복사
- TXT 파일 저장
- 입력 초기화

## 🔒 개인정보·보안

공문핏은 입력 내용을 서버로 전송하거나 저장하지 않습니다. 입력한 내용은 브라우저 화면 안에서만 처리됩니다.
