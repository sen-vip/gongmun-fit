# 📝 공문핏

공문핏은 학교 행정 공문 작성 시
`가. 나. 다. 라.` 항목 순서가 꼬이지 않도록 도와주는 **공문 구조 정리 도구**입니다.

입력한 항목 중 빈 항목은 자동으로 제외하고,
남은 항목만 다시 `가. 나. 다.` 순서로 정리해 줍니다.

## ✨ 주요 기능

* 공문 제목 입력
* 관련 문서 입력
* 본문 문장 입력
* 공문 세부 항목 입력
* 직접 입력 항목 추가
* 붙임 문서 입력
* 공문 본문 자동 생성
* 결과 복사
* TXT 파일 저장

---

## 🧾 기본 항목 구성

현재 기본 항목은 실무에서 자주 쓰는 핵심 항목 중심으로 구성되어 있습니다.

```text
가. 일시
나. 장소
다. 대상
라. 내용
마. 금액(소요예산)
바. 산출근거
사. 업체명
아. [직접 입력]
```

`운영방법`, `강사`, `기대효과`, `행정사항` 등은 기본 항목에서 제외했습니다.

필요한 경우 `+ 항목 추가` 버튼을 눌러 직접 입력 항목을 추가할 수 있습니다.

---

## ➕ 항목 추가 방식

처음 화면에는 `아. [직접 입력]` 항목까지 표시됩니다.

`+ 항목 추가` 버튼을 누르면 다음 항목이 순서대로 추가됩니다.

```text
자. → 차. → 카. → 타. → 파. → 하.
→ 거. → 너. → 더. → 러. → ... → 허.
→ 고. → 노. → 도. → 로. → ... → 호.
```

추가 항목은 항목명과 내용을 모두 직접 입력할 수 있습니다.

예시:

```text
아. 세부일정: 행사 세부 일정은 붙임 계획서 참고
자. 기타사항: 일정은 학교 사정에 따라 변경될 수 있음
```

---

## 🔁 자동 정렬 방식

공문핏은 사용자가 입력한 항목 중 **내용이 있는 항목만** 결과에 반영합니다.

예를 들어 화면에서 일부 항목을 비워두면,

```text
가. 일시
나. 장소
다. 대상
라. 내용
마. 금액(소요예산)
바. 산출근거
사. 업체명
아. 기타사항
```

결과에서는 입력된 항목만 다시 순서대로 정리됩니다.

```text
가. 장소: 시청각실
나. 내용: 안전교육 실시
다. 업체명: (주)OO
라. 기타사항: 일정은 학교 사정에 따라 변경될 수 있음
```

즉, 사용자가 `가.`, `나.`, `다.`를 직접 맞출 필요가 없습니다.

---

## 💰 금액 자동 정리

`금액(소요예산)` 항목은 금액 입력 시 자동으로 보기 좋게 정리됩니다.

예시:

```text
1000000
```

입력 후 결과:

```text
금1,000,000원(금일백만원)
```

---

## 📎 붙임 처리

붙임 문서가 있으면 공문 끝에 붙임 목록이 추가됩니다.

예시:

```text
붙임  1. 계획서 1부.
      2. 견적서 1부.  끝.
```

붙임이 없으면 마지막 본문 항목에 `끝.`이 붙습니다.

---

## 💾 저장 및 복사

생성된 공문 본문은 다음 방식으로 사용할 수 있습니다.

* `복사하기`: 결과 본문을 클립보드에 복사
* `TXT 저장`: 공문 제목을 파일명으로 하여 텍스트 파일 저장

---

## 🔒 개인정보 및 보안

공문핏은 입력한 내용을 외부 서버로 전송하지 않습니다.

입력 및 생성 작업은 사용자의 브라우저 안에서 처리됩니다.

---

## 🛠 사용 목적

공문핏은 다음과 같은 실수를 줄이기 위해 만들었습니다.

* `가. 나. 다.` 순서가 꼬이는 문제
* 중간 항목 삭제 후 번호를 다시 고쳐야 하는 문제
* 빈 항목이 공문에 남는 문제
* 붙임 문구와 `끝.` 처리가 헷갈리는 문제

---

## 📌 권장 사용 방식

1. 필요한 항목만 입력합니다.
2. 사용하지 않는 항목은 비워둡니다.
3. 기본 항목 외 내용은 직접 입력 항목에 작성합니다.
4. `공문 생성하기` 버튼을 누릅니다.
5. 결과를 복사하거나 TXT로 저장합니다.
