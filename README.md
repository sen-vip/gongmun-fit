# 📝 공문핏

공문핏은 공문 본문 작성 시 사용하는 번호 체계를 자동으로 정리해주는 웹 도구입니다.

## 이번 수정

- 본문 항목을 `가~하 → 거~허 → 고~호`까지 지원하도록 확장했습니다.
- 기본 화면에는 `타. [직접 입력]` 항목이 처음부터 표시됩니다.
- `+ 항목 추가` 버튼을 누르면 `파, 하, 거, 너, 더, 러... 호` 순서로 항목이 하나씩 추가됩니다.
- 추가 항목은 항목명과 내용을 직접 입력할 수 있습니다.
- 최종 결과는 빈 항목을 제외하고 입력된 항목만 다시 순서대로 재정렬합니다.

## 보안

입력 내용은 서버로 전송되지 않고 브라우저에서만 처리됩니다.
