# 📝 공문핏

## v1.8.1 공문 전체 순번 정리

- 기존 **직접 작성(칸칸이 작성)** 기능 유지
- **통째로 붙여넣기** 선택 영역을 크게 개선해 기능 전환이 한눈에 보이도록 변경
- 붙여넣은 공문의 본문 `1. 2. 3.` 순번 자동 재정렬
- 각 숫자 문단 아래 `가. 나. 다.` 순번을 별도 계층으로 자동 재정렬
- `붙임  1.`부터 이어지는 붙임 번호는 본문 숫자와 분리해서 별도로 재정렬
- `2026. 8. 20.` 같은 날짜는 숫자 문단으로 오인하지 않도록 보호
- 일반 문장, 빈 줄, 내용 자체는 그대로 유지
- 기존 확장 가나다 순번 `가~하 → 거~허 → 고~호` 지원
- 정리 결과 **복사 / TXT 저장** 지원
- 모든 처리는 브라우저 안에서 이루어지며 외부 서버로 전송하지 않음

## ✨ 주요 기능

- 공문 제목 입력
- 관련 문서 입력
- 본문 문장 입력
- 공문 세부 항목 입력
- 직접 입력 항목 추가
- 붙임 문서 입력
- 빈 항목 제외 후 가나다 자동 재정렬
- 기존 공문 전체 붙여넣기 순번 자동 정리
- 결과 복사
- TXT 파일 저장

```text

1. 관련
3. ~~하고자 합니다.
   가. 일시
   다. 장소
   다. 대상
```
